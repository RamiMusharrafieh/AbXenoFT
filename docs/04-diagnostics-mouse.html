Is the model more than a lookup table?

Antibody framework positions are highly conserved (mean positional conservation is 0.70), so a model can score high simply by predicting the most common residue at each position. The control is to build exactly that: a per-position consensus table from the training germlines only, and score it on the same masked positions.

The model beats it by 18.7 points, and the margin is concentrated precisely where the lookup table fails. Everything below is measured on 35 V genes the model never trained on.

Where the model earns its keep

Masked positions bucketed by how conserved they are in training. At near-invariant positions the lookup table is already right and the model adds nothing, correctly so. At variable positions, where a consensus table is close to useless, the model is still right five times in six. That gap is the evidence it learned context rather than position frequencies.

Accuracy along the framework

Every one of the 91 framework positions, model accuracy against that position's conservation. Both are fractions on one shared axis. The hardest positions cluster at the CDR boundaries: position 41 (last residue of FR2, abutting CDR2) falls to 43.7%, position 26 (second residue of FR2, abutting CDR1) to 55.4%. Those are Vernier-zone residues whose identity is coupled to the CDRs this dataset strips out, so the model has no context to infer them from.

By framework region

FR3 gains most, because it is the longest and most variable region, and it flanks CDR3. FR4 gains least because it is already near-invariant.

By held-out V family

IGHV2 is the sharpest case: the global consensus is dominated by IGHV1 and fits IGHV2 poorly (52%), yet the model reads it at 94%.

What it predicts when it is wrong

Error structure only: the diagonal is removed and each row renormalised over that residue's mistakes, so the question is "given a wrong call for a true X, what did it guess?" Residues are ordered by chemical class, so conservative substitutions appear as near-diagonal blocks. They do: M→L 11.6%, R→K 7.1%, N→T 8.2%, I→M 8.5%. The model errs biochemically, not randomly.

Latent space, before and after

PCA of mean-pooled embeddings for 1,200 sequences. Fine-tuning sharpens germline structure 3.7×: the ratio of between-family separation to within-family scatter rises from 1.22 to 4.56, families tightening (spread 0.63 → 0.23) as they pull apart. Held-out genes sit inside the trained manifold rather than off to one side: 80.3% fall within the trained 5th–95th percentile region, against 79.7% for trained points themselves. That is the geometric version of the 90.76% result: novel germlines are represented like familiar ones.

A correction caught during this run. My first pass computed the train/validation split after filtering to canonical-length sequences, which changed the group sizes and held out 37 genes instead of the 35 the model actually trained on. That contamination inflated the model to 92.87%. Deriving the split from every row first, as training did, gives the honest 90.76%.

Method: 4,000 held-out sequences × 13 masked positions = 52,000 predictions, 15% masking, top-1. Framework regions are fixed-length here (FR1 25, FR2 17, FR3 38, FR4 11 = 91 residues), so positions align exactly and the consensus table is well defined. The consensus is built only from training germlines, giving it the same information the model had. Source: analysis_qc.py.
